StudyNotes AI 📚

An AI-powered notes app for students, built according to the Product & Build Spec.

What's Built (v1 Scope)

✅ Rich Text Editor - Bold, italic, underline, headings, lists, code blocks, highlighting
✅ Local-First Storage - All data stored in IndexedDB, works offline
✅ PWA Support - Installable, works offline with service worker
✅ AI Transformation - "Clean this up" feature with multilingual support
✅ Course Organization - Group notes by course/subject
✅ Markdown Export - One-click export all notes as Markdown
✅ Usage Tracking - Silent logging of AI calls for future pricing decisions

How to Use

  1. Open index.html in a modern browser
  2. Create a course (e.g., "Biology 101")
  3. Start typing your lecture notes
  4. Click "Clean this up" to transform your notes with AI
  5. Toggle between Raw and Clean views

Architecture Principles

  • Local-first: Browser (IndexedDB) is source of truth
  • Offline-capable: Works without internet via PWA
  • Plain-text-adjacent: Export to Markdown with zero data loss
  • Never lose content: Raw notes always preserved

Technical Notes

AI API Integration: The app currently uses a placeholder URL. Replace AI_API_URL in src/utils/ai-service.js with your preferred AI service endpoint.

Service Worker: Requires HTTPS or localhost. Use a local server like python -m http.server 8000 or npx serve .

Browser Support: Chrome, Firefox, Edge, Safari (all modern versions)
